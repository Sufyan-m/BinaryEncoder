🐍 ENDCODER
💻 Can't Say It? Encode It!

ENDCODER is a simple Python tool that converts text into binary code using 0s and 1s.

✨ Features
📝 Convert text into binary.
🔢 Represent characters using 0s and 1s.
🐍 Built with beginner-friendly Python.
⚡ No extra packages required.
🚀 How to Run

Requirements: Python 3 installed on your computer.

Download or clone this repository.
Open the project folder in your terminal.
Run the program:
python main.py

On Windows, you can also use py main.py.

💻 Example
Enter your text: MIKASA

Binary: 01001101 01001001 01001011 01000001 01010011 01000001

Decoded message: MIKASA
