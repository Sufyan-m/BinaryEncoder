🐍 ENDCODER

Can't Say It? Encode It! 💻

A beginner-friendly Python project that transforms normal text into binary code using "0s" and "1s".

Turn your words into machine-readable binary representations!

⚙️ Installation

Requirements: Python 3 installed on your computer.

1. Clone the repository

git clone https://github.com/Sufyan-m/BinaryEncoder.git

2. Open the project folder

cd BinaryEncoder

3. Run the program

python main.py

Windows users can also run:

py main.py

🧠 How It Works

ENDCODER uses Python's built-in functions:

- "ord()" converts a character into its Unicode code point.
- "format()" converts that number into binary representation.
- "08b" formats the output with at least 8 binary digits.
- "join()" combines binary values into one string.
